Full-Stack Enterprise Platform

College360 — Comprehensive Campus Management System

🏆 College Hackathon Winner

A full-scale institutional operations engine unifying student attendance tracking, academic feedback, centralized records, and dynamic timetable generation under a unified, multi-tiered role-based access architecture.

Problem:

College administration was bottlenecked by fragmented spreadsheet rosters, untracked proxy attendance ("buddy punching"), and manual timetable scheduling clashes.

Solution:

Architected an end-to-end MERN stack application with strict JWT role-based access control, an automated conflict-free timetable scheduler, and centralized attendance logging.

Outcome:

Evaluated live in the CODESTORM Season 2 College Hackathon, securing 1st Place / Category Winner with zero data collisions and sub-200ms API latency.

Stack React, Node.js, Express, MongoDB, JWT, REST
Status Production Deployed & Evaluated

02
Biomedical AI & Diagnostics

Nuroliq AI — Deep Learning MRI Classification Engine

Applied Deep Learning

A clinical decision-support web application that analyzes neuroimaging MRI scans for classification and tumor detection using deep transfer learning, serving instant confidence scorings through an asynchronous Flask API.

Problem:

Manual radiological analysis of brain MRI scans is time-sensitive and suffers from diagnostic variability. Training deep nets from scratch on small clinical datasets causes overfitting.

Solution:

Employed transfer learning using an EfficientNetB0 backbone pre-trained on ImageNet with custom data augmentation pipelines, served via asynchronous Flask micro-endpoints.

Outcome:

Delivered rapid, reproducible classification probabilities across tumor subtypes with high validation accuracy, serving inferences in under 1.2 seconds per slice.

Stack Python, TensorFlow, EfficientNetB0, Flask, OpenCV
Domain Computer Vision / Medical Imaging

03
Defensive Intelligence

ML Phishing Detection Suite & Chrome Extension

Security & Machine Learning

An intelligent URL classification pipeline and browser extension that performs real-time lexical, entropy, and structural analysis to detect malicious zero-day phishing sites before the user exposes credentials.

Problem:

Static URL blocklists and reputation databases fail against fast-flux domains and ephemeral phishing URLs generated dynamically in active zero-day campaigns.

Solution:

Extracted 30+ lexical, domain-entropy, and protocol-level features from over 100,000 verified URL samples. Trained supervised classification trees in Scikit-learn integrated with Manifest V3.

Outcome:

Achieved high predictive accuracy on unseen malicious URLs, providing users with instant sub-50ms browser warning banners prior to page DOM rendering.

Stack Python, Scikit-learn, NLP, Flask, Chrome Extension V3
Focus Heuristic & ML Threat Defense

04
Biometrics & Geolocation

Vision Attendance System V2 (Face + Geofence)

Computer Vision

A touchless enterprise attendance platform combining real-time camera face verification, device geolocation perimeter checks, and timed QR token fallback authentication to prevent spoofing and proxy logging.

Problem:

Physical fingerprint scanners cause hygiene bottlenecks and allow attendance fraud through photo spoofing or location spoofing in hybrid work and educational environments.

Solution:

Integrated OpenCV face recognition with deep embeddings matching, reinforced with client-side GPS geofencing perimeter validation and dynamic rotating cryptographic QR tokens.

Outcome:

Eliminated proxy punch fraud entirely in deployment trials, handling check-ins within 1.5 seconds per user with strict location verification.

Stack Python, OpenCV, Deep Learning, Flask, SQLite
Security Geofence Validation + Biometric Match

05
Human-Computer Interaction

Real-Time Sign Language to Text Converter

Accessibility AI

An assistive computer-vision application translating American Sign Language (ASL) finger-spelling gestures into readable English text in real time, bridging communication barriers for the speech- and hearing-impaired.

Problem:

Communication between sign language users and non-signers requires costly interpreters. Real-time vision models struggle with rapid motion blur and complex finger overlaps.

Solution:

Extracted 21 3D spatial hand landmarks per frame using MediaPipe Hands, fed normalized spatial vectors into a custom convolutional classifier, and generated continuous buffered text.

Outcome:

Achieved smooth 30+ FPS real-time translation on standard webcams without dedicated GPU accelerators, converting gestures into readable sentences instantaneously.

Stack Python, MediaPipe, OpenCV, TensorFlow, CNN
Objective Real-Time Accessibility Tech
